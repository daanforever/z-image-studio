# code-review-check
Verify code review results and filter out false positives

# Instructions

Act as a secondary reviewer to validate the previous code review findings against the actual source code. Critically evaluate each reported issue to eliminate false positives, hallucinations, and unverified assumptions. Keep only the genuinely confirmed problems. Present the refined list of verified findings ordered by severity, maintaining focus on bugs, behavioral regressions, security issues, and missing tests. Do not make code changes unless explicitly requested.
