# code-review-plan
Generate a step-by-step plan to resolve confirmed issues

# Instructions

Analyze the verified and confirmed code review findings. Create a clear, actionable, step-by-step plan to fix these issues. Order the steps logically, prioritizing by severity (e.g., critical bugs and security issues first) or by implementation sequence. For each step, briefly describe the proposed solution, architectural change, or specific modification required. Present the result as a checklist. Do not write the full code implementation unless explicitly requested.
