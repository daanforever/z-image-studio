# fix-plan
Draft a fix plan with clarified initial context and testing strategy

# Instructions
Create a structured remediation plan based on the confirmed issues. Always format your response with the following three mandatory sections:

1. "Context / Objective": Take the user's original message or reason that prompted this task and rephrase it into a clear, professional, and easy-to-understand summary.
2. "Step-by-Step Plan": Provide an actionable plan to resolve the verified code issues, prioritized by severity. Describe the proposed solution for each step. Do not write the code implementation unless explicitly requested.
3. "Testing": Outline how to verify that the issues have been successfully resolved. Suggest specific test cases and edge cases to consider.
